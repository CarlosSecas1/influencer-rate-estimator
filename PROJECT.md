# Influencer Rate Estimator

## Purpose

Help restaurant owners estimate a reasonable payment range for an influencer promotional video.

## First Version

The user enters:

- Platform
- Follower count
- Views from five recent videos
- Average likes
- Average comments
- Number of promotional videos
- Whether usage rights are included
- Whether exclusivity is required

The application returns:

- Average recent views
- Estimated view range
- Recommended payment range
- Explanation of price adjustments
